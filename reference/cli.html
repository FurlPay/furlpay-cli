CLI Command Reference ​

Every command accepts --json where output is structured. Global flags: --env sandbox|live, --api-base <url>, --width <cols>.

Session & account ​

CommandDescription
furlpay login [--device|--email <addr>]Browser device flow (RFC 8628) or headless email OTP
furlpay whoamiActive session, verified email, KYC tier, Safe address
furlpay logoutRevoke the local session cookie
furlpay env sandbox|liveSwitch environment
furlpay balanceToken balances across Arbitrum, Base, Optimism, Ethereum
furlpay dashboardAggregate dashboard view

CommandDescription

furlpay send <amt> <0xaddr> --token USDC --chain arbitrumRaw address transfer

Oracle & Solana (live read-only) ​

CommandDescription
furlpay oracle price <ASSET>Multi-source USD quote (Coinbase/Kraken/Binance/Jupiter), median + agreement gate — DISAGREEMENT/UNAVAILABLE carry a null price
furlpay oracle sourcesSource inventory: endpoints and covered assets (Pyth gateway shown inactive unless configured)
furlpay solana statusLive cluster status from mainnet RPC (epoch, slot, block height)
furlpay solana balance <addr>Lamport balance via live RPC (base58-validated)
`furlpay solana price <mintalias>`
furlpay solana quote <in> <out> <raw-amount>Indicative Jupiter route — labeled INDICATIVE, nothing in this build can fill it
furlpay mainnet readinessEvery execution prerequisite, PASS/FAIL/BLOCKED/NOT_VERIFIED — exit 1 = not ready
furlpay mainnet statusPer-surface network/mode/status snapshot (read-only)
furlpay mainnet dry-run <SYM> --side --sizeReal risk-engine evaluation of a hypothetical order — never signs, never submits
