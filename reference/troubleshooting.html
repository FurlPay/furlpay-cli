Troubleshooting ​

Every error the CLI refuses with is a designed signal, not a bug to work around. Grouped by what you were trying to do. Exit codes: 0 success; non-zero refusal (per-command codes where documented, e.g. tx verify semantics or the MCP execution-mode exit 47).

Install & update ​

SymptomCauseFix
furlpay: command not foundnpm global bin not on PATHnpm config get prefix → add its bin to PATH, or reinstall with the installer script
Install script warns about mirrorsunofficial registry overrideremove the mirror from .npmrc; the script warns rather than proceeding silently
furlpay update stallsnpm global permissionsuse the installer script (never sudo) or npm config set prefix to a user-writable path

Wallets & signing ​

SymptomCauseFix
Ledger probe finds nothingapp not open / USB HID permissionsopen the Stellar app on the device; on Linux check udev rules
"Fail closed without signer" on HLP/perpsno signer configuredexport HYPERLIQUID_PRIVATE_KEY (or ETH_PRIVATE_KEY) — there is deliberately no simulated fallback
